# HKDSE S4 Biology Practice (Chapters 1–5)

Offline static site: open `index.html` in any browser.

## Structure
- `index.html` — home, MCQ practice, structured practice, browse
- `css/style.css` — layout and theme
- `js/app.js` — practice UI
- `data/questions.js` — question bank
- `MISSING_ANSWERS.md` — items needing teacher verification
- `source/` — original docs + `txt/` extracts

## How to use
1. Open `index.html`.
2. Pick a chapter card or use **MCQ practice** / **Structured practice**.
3. For structured questions, draft an answer then **Show marking scheme** (yellow = key words).

## Figures / screenshots
Diagram-only questions use local files under `img/` (quiz embeds, chapter media, and PDF page screenshots in `img/pages/`). Open `index.html` offline — no network needed for figures.
